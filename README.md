# AviUtl2 Hub (AviUtl2_Plugins)

AviUtl2を拡張するプラグインやスクリプトを一覧でき、簡単に検索・導入できるHubサイト（SPA）です。

## 技術スタック
- **フロントエンド**: HTML5, Vanilla JavaScript, Tailwind CSS (CDN), Lucide Icons
- **バックエンド (Headless CMS)**: microCMS
- **ホスティング**: GitHub Pages

## コントリビュート
新しいプラグインの報告や記載内容の修正等は、サイト内の「情報提供（Contribute）」ページに設置されているGoogleフォームよりお知らせください。
